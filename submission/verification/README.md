# Path-normalized verification records

These are public path-normalized copies, not byte-for-byte literal terminal transcripts. Local project-root prefixes are removed, the local Python interpreter is represented as python, and machine-specific TeX prefixes as <TEX_ROOT> and <TEX_BIN>. Command working directories are relative to the source root. Scientific values, assertions, verdicts, timings and exit statuses are unchanged.

Original literal stdout/stderr and the full local evidence ledger remain in the private delivery evidence and VERIFICATION.txt, not exposed here. scientific-checks.json records the executed suite. R5-restored-audit logs are the final audit after restoring all 59 released packed records; earlier R5-audit logs precede the independent 19-case packed regeneration.

The proof notes state the mathematical assumptions and trusted bases. Re-executing the released implementation is not an independent implementation or proof-assistant verification.
